# Agenda Santi

App personale (web app installabile su iPhone e Mac): spese, scadenze e addebiti fissi, entrate e saldi, agenda, sport e cibo.

- Nessuna build: file statici (`index.html`, `app.js`, `style.css`), pubblicabili con GitHub Pages.
- Su iPhone: apri il sito in Safari → Condividi → «Aggiungi alla schermata Home».
- I dati per ora restano nel browser del dispositivo (localStorage). Sincronizzazione iPhone/Mac in arrivo.
